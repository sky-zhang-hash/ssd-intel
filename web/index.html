SC26 三线并进：PCIe 6.0 主控、盘内 NPU、GPU 直连 SSD 同时落地

这一期的主线是企业级 SSD 的架构分叉：慧荣 SM8466 把 PCIe 6.0 拉到 28GB/s，铠侠 GP2 用 XL-FLASH 做 GPU 直连，群联则把 NPU 和 64GB 内存塞进盘里。上游同时收紧——三星西安加码 V9、美光新加坡 HBM 封装厂进设备，NAND 与 DRAM 的产能正被 AI 重新分配。

铠侠与英伟达合作，用 NVIDIA SCADA 软件与铠侠 SSD 把 GPU 可用显存扩展到 PB 级，演示系统在 GB200 NVL72 机柜上安装 144 块铠侠 XD8 系列 7.68TB E1.S NVMe SSD，处理含 2 万亿向量的数据库。机理是用 Storage-Next 架构把 SSD 作为 GPU 的二级显存池，避免数据集在 HBM 与慢速存储间反复搬运。这直接拉动 E1.S 高密度企业级盘的用量，单机柜 144 块意味着 SSD 采购量与 GPU 机柜强绑定。

144 块盘对应一台机柜，SSD 正从通用存储变成 GPU 系统的配套件，议价权向英伟达倾斜。

铠侠发布 KIOXIA GP2 系列 PCIe 6.0 NVMe SSD，基于第三代 XL-FLASH，512 字节块下随机读取超过 18M IOPS，约为 GP1 的两倍，符合 NVMe 2.3，专为 GPU 直接访问优化。XL-FLASH 属于 SCM 级闪存，读延迟远低于 TLC，配合 PCIe 6.0 带宽才能让 GPU 绕过主机 CPU 直接取数。GP2 的定位不是通用存储，而是 AI 推理与 HPC 中 HBM 容量不足时的外溢层，产品线将与高 IOPS 企业级 SSD 形成分工。

18M IOPS 只在 512B 小块成立，实际 AI 负载的块大小分布决定它能否兑现两倍提升。

超能网今天 18:49↗ 颗粒产品AI

SK 海力士工程师崔康植在首尔大学 AI 半导体论坛透露，公司目标 4 至 5 年内量产 3D DRAM，首款商用产品堆叠 100 层存储单元；达到当前 10nm 级 DRAM 同等密度约需 75 层，综合其他因素后第一代定为 100 层。现有设备可支撑 100 层，但 200 层以上需要专用新设备。平面 DRAM 微缩逼近物理极限，垂直堆叠是延续密度曲线的路径，但 3D DRAM 量产前 HBM 仍将挤占 DRAM 产能，SSD 的 DRAM 缓存成本压力不会缓解。

2031 年才量产，对当前 SSD 物料成本没有直接影响，别把它当短期利好读。

GPU 交付后移会把 eSSD 需求高峰推到 2027 下半年，短期订单波动加大。

据 Nikkei Asia，三星与 SK 海力士正探索授权长江存储的 Xtacking 3D NAND 设计，两家韩国厂商在第四季度推进相关洽谈。Xtacking 将存储阵列与外围电路分开制造再键合，与铠侠 CBA 思路同源，能在不缩小单元的前提下提升密度和 IO 速度。若授权落地，意味着中国 NAND 厂商的架构首次反向输出到全球前两大存储厂，也说明 3D NAND 的竞争已从层数转向键合与外围工艺。对颗粒供应格局的影响是长期的，短期不改变产能分配。

授权谈判存在地缘政治变数，谈成与否都不改变 2027 年 NAND 供给偏紧的基本盘。

TechPowerUp今天 00:25↗ 颗粒

TrendForce 报道，三星 HBM4 基础裸片采用自家 4nm 工艺，产线自去年末起满负荷运转，但仍面临产能不足，预计 2027 年需求翻倍至每月约 3 万片晶圆。目前仅在华城和平泽部分产线生产基础裸片，三星计划扩大产线。基础裸片是 HBM4 的逻辑层，用 4nm 代工产能，与逻辑芯片争夺同一批晶圆。这意味着 HBM 扩张不仅吃 DRAM 产能，还吃先进逻辑产能，间接推高整个存储链的资本开支优先级。

基础裸片产能是 HBM4 出货的隐性天花板，三星的扩产节奏决定其 2027 年份额。

铠侠预览第三代 XL-FLASH，采用 CBA 架构，存储阵列与外围电路分别制造后键合，位密度较第二代提升 70%，3μs 平均读取延迟仅为 BiCS8 TLC 的 1/10，512B 读取能效也优于上代，计划 2027 年 3 月向特定客户交付功能评估样品。CBA 键合让外围电路可以用更先进的逻辑工艺，从而在相同面积内提高密度并压低延迟。对 SSD 产品线而言，这意味着 SCM 层可以在不牺牲容量的前提下替代部分 DRAM 缓存角色，直接影响企业级盘的 DRAM 配比与成本结构。

3μs 延迟仍比 DRAM 高两个数量级，它替代的是 SLC 缓存而非内存，别高估定位。

《首尔经济日报》11 月 23 日披露，三星计划改造西安第二工厂（X2），加码第九代垂直 NAND（V9）产能，面向 AI 数据中心市场，存储长约订单持续饱满。V9 是三星当前最高层数代际，把最新代际放到海外工厂说明其对中国 NAND 供应地位的重视。改造而非新建，意味着产能释放周期较短，但设备搬入与爬坡仍需时间。这批产能主要流向企业级 eSSD，对消费级 NAND 供给的缓解有限。

V9 优先供数据中心，消费级 SSD 颗粒分配在 2027 年仍偏紧。

群联推出 Pascari Space 太空专用 SSD 解决方案，基于其超过 26 年 NAND 存储技术与经太空任务验证的积累，结合 IMAGIN+ 定制化 NAND 与 ASIC 设计服务，针对不同太空任务量身定制，此前技术已用于 NASA 火星探测车。太空场景的核心约束是辐射导致的位翻转与宽温循环，需要定制固件、ECC 策略与筛选流程，而非标准企业级盘改标。这为群联打开商业太空与轨道基础设施这一小批量高毛利市场，也验证其定制化 ASIC 服务能力。

太空订单量小，战略意义大于营收；真正的看点是定制 ASIC 服务能否复制到工业与车规。

超能网11-21 22:00↗ 颗粒封装产品AI供应链价格

群联在 SC26 详细介绍两款企业级 SSD 设计：一款内置 NPU 与 64GB、130GB/s 带宽内存，支持在盘内直接运行 PyTorch、vLLM、OpenVINO 和 llama.cpp；另一款在单一控制器后融合高速 pSLC 缓存与大容量 QLC。盘内 NPU 的思路是把向量检索、KV Cache 等数据密集型操作下沉到存储侧，群联称适用负载下数据传输量可降至原来的 1/10 至 1/100，同时减轻主机 CPU 负担。pSLC+QLC 混合介质则用缓存层吸收写放大，延长 QLC 寿命。

盘内 NPU 目前仍是开发阶段，生态与编程模型未定，短期难进主流采购清单。

斯托瑞吉11-21 09:48↗ 主控颗粒产品

慧荣在 SC26 首次公开展示 SM8466，这是其高端 MonTitan 系列首款 PCIe 6.0 SSD 主控，最终版本近期完成流片，搭载该主控的 SSD 预计 2027 年末至 2028 年初上市。规格为 PCIe 6.0 x4、16 通道、顺序 28GB/s、4K 随机 7M IOPS，符合 NVMe 2.0 与 OCP NVMe 2.5。PCIe 6.0 改用 PAM4 信号，通道损耗与误码率余量比 NRZ 时代更紧，16 通道并行对主控 SerDes 和封装走线要求显著提高。这意味着数据中心 SSD 的竞争点从颗粒带宽转向主控信号完整性与固件调度，2027 年前后企业级产品线将出现一轮主控换代窗口。

流片到量产还有两年，中间任何 PAM4 重定时器或固件问题都会把上市窗口推到 2028 年。

Microchip 发布第四代 Flashtec NVMe 4016 主控，PCIe Gen5 x4 接口、16 个可编程 NAND 通道，吞吐超过 14GB/s，随机性能超过 3M IOPS 量级。可编程通道意味着同一颗主控能适配不同厂商的 TLC/QLC 颗粒与不同代际 NAND，对需要长期供货的企业级与工业客户是降低重新认证成本的卖点。在 PCIe 6.0 主控尚未量产的窗口期，Gen5 16 通道方案仍是 2026-2027 年企业级 SSD 的主力选型，Microchip 借此巩固非头部云厂商的份额。

可编程通道是双刃剑：灵活度高，但固件调优责任落在客户身上，量产节奏取决于客户团队。
