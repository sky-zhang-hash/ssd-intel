SSD 情报日报 · 装到手机 PWA

把它当 App 用

iPhone / iPad

  1. 用 Safari 打开下面的地址（微信里打开不行，得先点右上角「…」→「在浏览器中打开」）
  2. 点底部的分享按钮（方框向上箭头）
  3. 往下找，点「添加到主屏幕」，名字用默认的「SSD 日报」就行
  4. 回到桌面，点那个蓝色图标——全屏、没有地址栏，和 App 一样

必须用 Safari。iOS 上 Chrome / 微信 / 夸克都没法把网页加到主屏。

Android

  1. 用 Chrome 打开下面的地址
  2. 点右上角的三个点菜单，选「安装应用」或「添加到主屏幕」
  3. 桌面上会出现图标，点开是全屏的

小米 / OPPO / vivo 自带浏览器也能加，但更新可能不及时，Chrome 最稳。

电脑上

Chrome / Edge 打开地址后，地址栏右侧会出现一个「安装」小图标，点它就会变成独立窗口的桌面应用。

用手机扫这个

https://sky-zhang-hash.github.io/ssd-intel/

手机相机扫一下就能打开；打不开就直接把上面这行地址打进浏览器。

装完之后

  • 每天早上 08:10 云端自动更新，点开就是最新的
  • 没网也能看到上一次的内容（Service Worker 缓存了页面外壳）
  • 在页面顶部往下拉就能手动检查更新，会告诉你是不是已经是最新
  • 「收藏」存在这台手机本地，换设备不会同步
  • 点来源名会跳到原文；公众号文章会在微信里打开
